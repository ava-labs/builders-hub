## Overview

SolidRPC is an EVM JSON-RPC provider for production applications, wallets, and developers. It offers authenticated full and archive access and a keyless public endpoint for Avalanche C-Chain.

## Features

- **Authenticated RPC**: Production HTTPS endpoints with account-level limits and usage analytics
- **Archive Access**: Historical state access for supported networks
- **Public RPC**: Keyless Avalanche C-Chain endpoint for wallets and lightweight application traffic
- **Clear Throttling**: HTTP 429 responses with JSON-RPC error details and retry headers

## Endpoints

```text
# Keyless public C-Chain endpoint
https://rpc.solidrpc.io/public/evm/43114

# Authenticated C-Chain endpoint
https://rpc.solidrpc.io/<API_KEY>/evm/43114
```

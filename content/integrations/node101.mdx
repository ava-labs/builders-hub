## Overview

node101 provides managed JSON-RPC infrastructure for Avalanche C-Chain. The service supports applications and institutional workloads that require managed blockchain access and operational support.

## Features

- **Managed RPC Access**: Access Avalanche C-Chain through shared service plans or dedicated node infrastructure.
- **HTTP and WebSocket Support**: Use HTTP endpoints and, on supported plans, WebSocket connections for application traffic.
- **Trace APIs**: Use trace methods for debugging and transaction analysis on supported plans.
- **Service Monitoring**: Monitor RPC service usage and infrastructure status.
- **Operational Support**: Receive 24/7 support from the node101 infrastructure team.

## Documentation

For service details and plan availability, visit the [node101 Avalanche RPC page](https://node101.io/en/rpc/avalanche).

## Use Cases

- RPC access for Avalanche C-Chain applications and wallets
- Infrastructure for exchanges, custody platforms, and institutional services
- Transaction analysis and blockchain data workflows

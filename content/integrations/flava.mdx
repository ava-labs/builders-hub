## Overview

Avalanche AI Flow is an open-source visual development platform inspired by Node-RED. It combines drag-and-drop node workflows with powerful AI to make building on Avalanche dramatically more accessible.

Users describe what they want in plain English, visually connect nodes, and the AI generates clean, audited, production-ready Solidity smart contracts optimized for Avalanche.

## Features

- **AI Smart Contract Builder**: Turn natural language prompts into optimized Solidity code
- **Visual Node Flow Editor**: Drag-and-drop workflow (Prompt → Generate → Audit → Deploy)
- **Smart Contract Auditor**: AI-powered security review, risk scoring, and Avalanche best practices
- **One-Click Deployment**: Deploy directly to Avalanche Fuji testnet
- **Developer-Ready Output**: Clean, copyable code with comments and events
- **Avalanche Native**: Built specifically for C-Chain with future Subnet support

## Getting Started

1. **Visit the App**: Go to [fl-ava.vercel.app](https://fl-ava.vercel.app)

2. **Start Building**:
   - Open the visual editor
   - Click **"Start Prompt"** and describe your smart contract idea
   - Connect the nodes (Prompt → AI Builder → Auditor → Deploy)

3. **Generate & Audit**:
   - Use the AI Builder to generate Solidity code
   - Run the Auditor to check for issues and get recommendations

4. **Deploy**:
   - Use the Deploy node to launch your contract on Avalanche Fuji testnet

5. **Copy Code**:
   - Copy the final Solidity code for further development

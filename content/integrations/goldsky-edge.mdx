## Overview

Goldsky Edge RPC provides Avalanche C-Chain mainnet (chain ID 43114) access through an HTTPS JSON-RPC endpoint.

## Features

- **Historical data**: Archive queries, `debug_*`, and `trace_*` methods.
- **Request routing**: Multi-region CDN with automatic upstream failover.
- **Pricing**: $5 per million requests, with a one-time $100 Starter credit.

## Getting Started

Test with the rate-limited public key at `https://edge.goldsky.com/standard/evm/43114?key=demo`. Create an [account](https://app.goldsky.com) for your own API key. Edge RPC supports HTTPS requests; keep WebSocket subscriptions on another provider.

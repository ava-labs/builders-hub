## Overview

NOWNodes provides managed RPC access to Avalanche, allowing developers to connect to C-Chain, P-Chain, and X-Chain without deploying or maintaining their own node infrastructure.

## Features

- **C-Chain, P-Chain, and X-Chain Access**: Access EVM, PlatformVM, and AVM methods through NOWNodes infrastructure.
- **WebSocket Support**: Use WSS connections for real-time Avalanche blockchain data.
- **BlockBook API**: Access indexed address, transaction, balance, and block data.
- **High Availability**: Managed infrastructure designed for reliable blockchain access.
- **24/7 Technical Support**: Technical support for infrastructure and API connectivity.

## Getting Started

1. Create a NOWNodes account and obtain an API key.
2. Select Avalanche from the available networks.
3. Connect to the required Avalanche endpoint.
4. Use the Avalanche API documentation to explore available methods.

## Documentation

For endpoint configuration, supported methods, and request examples, visit the [NOWNodes Avalanche API documentation](https://docs.nownodes.io/avax.html).

## Use Cases

- **dApps and DeFi**: Connect applications to Avalanche C-Chain through EVM-compatible RPC methods.
- **Validator and Staking Applications**: Query P-Chain validator, staking, subnet, and network data.
- **Wallets and Exchanges**: Access transactions, balances, blocks, and Avalanche assets.
- **Real-Time Applications**: Receive blockchain data through WebSocket connections.
- **Blockchain Data Services**: Retrieve indexed Avalanche data through BlockBook APIs.
